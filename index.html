How it works

Three separate paths. Do not mix them up.

  1. Free browser self-check. Use the Release Evidence Check or cost tools. No signup. No code upload. No scan.
  2. Optional written inquiry. If you want an operator-assisted plan, use the beta form. Do not send source, credentials, or customer data.
  3. Scoped assessment only after writing. Work starts only if scope, access, capacity, price, and date are agreed in writing.

FAQ

Does a free tool scan my app?

No. The Release Evidence Check and calculator run in your browser. They do not import source or run your test suite.

Is the $499 pilot a live checkout?

No. It is a proposed one-time price for a written, scoped review. Nothing on this page charges a card.

Is this a security certification?

No. It is not a penetration test, production certification, or a guarantee that the app is safe to ship.

What if JavaScript is off?

The form still posts with the browser’s normal submit. Tool pages that need scripts say so on those pages.
