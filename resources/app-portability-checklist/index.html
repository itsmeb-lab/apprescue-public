Checklist · self-reported, not an automated scan

A code export is not a working replacement.

Before you switch AI app builders, collect the pieces the destination will not invent for you. A repository or zip can hold source files and still omit the database, auth provider ownership, secrets, DNS, and a practiced rollback.

Author: AppRescue. Reviewed 13 September 2026. This page does not solicit secret values and does not claim your app is secure or correctly migrated.

Never paste secrets here. Checkboxes stay in this tab only. Record environment-variable names, not values. Pair cost questions with the running-cost calculator and test evidence with the Release Evidence Check.

Portability checks

Lovable documents GitHub/GitLab/Bitbucket sync and a Download codebase action in Project settings → Git or at the bottom of the code-editor file tree (paid plans). Replit documents Download as zip from the file-tree three-dot menu, with a Shell zip fallback, plus a Git pane for a connected remote. Lovable GitHub docs · Replit projects and files · Replit Git pane.

Lovable Cloud export is More → Cloud → Overview → Advanced settings → Export project data. The official page says the file includes schema and table data, not storage files, Edge Function code, secrets, or usable user passwords; one export per 24 hours; export file at most 5 GB. You cannot download exports after Cloud is removed, and credits-and-usage docs say Cloud data cannot be accessed or exported while services are paused at zero balance. Replit’s data tools document export from Database → My Data. Replit also states that copying a project to another account does not include the database, secrets, or deployment configuration. Lovable Advanced settings · Replit, Work with your data · Replit projects and files.

Note which provider owns users, where the callback URLs live, and whether password hashes will survive a move. Lovable’s export notes say user passwords are not exported in usable form, so plan a reset flow. This is configuration ownership, not a security audit.

Replit keeps development Secrets separate from deployment secrets by design. Lovable distinguishes backend Secrets from browser-exposed VITE_ names. Write names only: DATABASE_URL, RESEND_API_KEY, never the secret itself.

Registrar login, DNS host, and TTL for apex and www records. A builder-issued preview URL is not domain ownership.

An installable zip does not establish that every package may be redistributed or that a clean install succeeds on the destination.

Restore synthetic or authorized test data into a staging project. Confirm the app boots, migrations apply, and a critical workflow runs. Presence of an export file is not a restore.

Replit’s project-help page states it no longer supports rolling a published app back to a previous version; the documented path is roll the project to a checkpoint, then publish again. Lovable Cloud removal permanently deletes the instance. Keep the previous builder available until the new deploy is rehearsed. Replit projects and files.

What this does not prove

  • That the destination host will accept the export, or that the app is deployable there.
  • That auth, payments, or file storage were migrated correctly.
  • Any automated security or correctness claim.

Checkboxes are a memory aid in this browser tab. They are not uploaded and they are not an AppRescue certification. AppRescue beta consideration is our own service, not a stamp that a migration is safe.
